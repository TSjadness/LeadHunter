# Pipeline Pocket Compass

Em resumo, Chaves, esse prompt que eu tô lhe mandando é um prompt pra criar uma plataforma de leads que já tem as API. Então, você vai fazer o quê? Você vai fazer esse projeto como tá aí e vai fazer as melhorias que você achar que precisa ser feita. Então você vai fazer um sistema de login, sistema de armazenamento. Aí você pode usar o que for melhor, se é Firebase ou Supabase, ou armazenamento interno aí pra poder salvar os dados. Você cria uma conta de login pra mim, já manda o login certinho, aí tem que estar totalmente funcional. Realiza os testes, tudo certinho, se tá trazendo a requisição, com certeza me manda o projeto, faça o projeto completo, no caso.
